#  名词解释
1. PCBA(Printed Circuit Board Assembly)
印刷电路板组装件，将电子元件通过焊接工艺固定到PCB上的成品
2. PCB(Printed Circuit Board)
印刷电路板，由绝缘基材、导电线路和焊盘组成的三维结构载体
3. PDM(Product Data Management)/PLM(Product Lifecycle Management)
产品数据管理/产品生命周期管理
4. CIS(Component Information System)
cadence 元器件库管理
5. Typ(Typical)
典型值
6. EVT(Engineering Verification Test)
工程验证测试阶段，电子方案验证
7. DVT(Design Verification Test)
设计验证测试阶段
8. PVT(Production Verification Test)
生产验证测试阶段，制程验证
9. MVT(Mass-Production Verification Test)
量产验证测试
10. TVS(Transient Voltage Suppressor)
瞬态抑制二极管
11. ESD(Electro-Static Discharge)
静电放电，两种带电材料或物体之间由接触、短路或电介质击穿引起的瞬时电流流动；气压、温度和湿度等因素会影响电场强度；造成所有电子元器件或集成电路系统过度电应力破坏的主要元凶，损伤毁灭性和永久性，会造成电路直接烧毁
12. EMC(Electro Magnetic Compatibility)
电磁兼容，对电子产品在电磁场方面干扰大小(EMI)和抗干扰能力(EMS)的综合评定
13. IMU(Inertial Measurement Unit)
惯性测量单元，电子设备，用于测量和报告物体的三个基本线性运动(加速度)和三个基本角运动(角速度)
14. HUB
集线器
15. oz
盎司[àng sī]
16. AIoT
Al+loT,智能物联=人工智能+物联网。简单来说,Al像是大脑,负责数据处理,loT是神
经末梢网络,负责连接、数据收集、数据反馈。
17. OCSP
在线证书状态协议
18. TBD
To Be Determined
待定
19. MUX
Multiplexer
多路复用器(模拟开关)
20. REFCLK
Reference Clock
参考时钟
21. SYNC
Synchronize / Synchronization
同步
22. 上件
端接电阻在总线首、末两端上件，中间节点空贴
23. VDENC
Video Encoder
视频编码器
24. NPU
Neural Processing Unit
神经网络处理单元
25. OSC
Oscillator
振荡器
26. PLL
Phase-Locked Loop
锁相环
27. PMU
Power Management Unit
电源管理单元
28. FSPI
Fast Serial Peripheral Interface
高速串行外设接口
29. MSS
Memory System Subsystem
内存系统子系统
30. MIPI
Mobile Industry Processor Interface
移动行业处理器接口
31. ALS
Ambient Light Sensor
环境光传感器
32. AFE
Analog Front End
模拟前端
33. DNP
Do not Populate
该元件在生成PCB板时不需要贴装
34. LGA
Land Grid Array
栅格阵列封装
35. FPU
Floating Point Unit
浮点运算单元
36. RTC
Real Time Clock
实时时钟
37. PRD
Product Requirements Document
产品需求文档
38. SDIO
Secure Digital Input Output
安全数字输入输出
基于 SD 卡物理总线扩展的外设通信协议
