# Finder

Finder（访达）是 macOS 自带的文件管理工具，主要用来浏览、查找和管理 Mac 中的文件。

这里整理一些平时比较常用的 Finder 功能和快捷键，方便以后快速查找。

---

## 1. 显示路径栏

打开：

```text
Finder → 显示 → 显示路径栏
```

快捷键：

```text
⌥ + ⌘ + P
```

开启后，Finder 底部会显示当前文件夹所在的位置，例如：

```text
Macintosh HD > 用户 > 用户名 > 下载 > 素材
```

路径栏中的文件夹也可以直接点击，用来快速跳转到对应目录。

---

## 2. 显示状态栏

打开：

```text
Finder → 显示 → 显示状态栏
```

开启后，可以在 Finder 底部看到：

- 当前文件夹有多少个项目
- 磁盘剩余空间

属于一个可以按个人习惯决定是否开启的功能。

---

## 3. 文件扩展名

进入：

```text
Finder → 设置 → 高级
```

可以找到：

```text
显示所有文件扩展名
```

开启后可以直接看到：

```text
照片.jpg
视频.mp4
文档.pdf
压缩包.zip
```

不过开启以后，应用程序也可能显示：

```text
Safari.app
Screen Studio.app
```

所以这个功能**不一定需要开启**。

如果经常处理图片、视频、代码、压缩包等不同类型的文件，可以考虑打开；普通使用保持默认即可。

---

## 4. Space 快速预览文件

选中文件后按：

```text
Space
```

可以直接快速预览文件，而不需要打开对应 App。

常见支持：

- 图片
- 视频
- PDF
- 音频
- 文本文档
- 部分办公文件

再次按 `Space` 即可关闭。

打开快速预览后，还可以使用方向键切换同一文件夹中的其他文件。

---

## 5. 直接前往指定路径

如果网上的教程给出：

```text
~/Library/Application Support
```

这种路径，不需要自己一层一层找。

直接按：

```text
⌘ + ⇧ + G
```

打开「前往文件夹」。

输入：

```text
~/Library/Application Support
```

按回车即可直接进入。

---

## 6. `~` 是什么意思？

Mac 路径中经常会看到：

```text
~
```

它代表当前用户的个人目录。

例如用户名是 `zhezhe`：

```text
~
```

相当于：

```text
/Users/zhezhe
```

所以：

```text
~/Downloads
```

相当于：

```text
/Users/zhezhe/Downloads
```

而：

```text
~/Library
```

相当于：

```text
/Users/zhezhe/Library
```

---

## 7. 打开隐藏的 Library

当前用户的 Library（资源库）默认是隐藏的。

最快的方法：

```text
⌘ + ⇧ + G
```

输入：

```text
~/Library
```

即可进入。

还有一种方法：

```text
Finder → 前往
```

然后按住：

```text
Option
```

菜单中就会出现：

```text
资源库
```

需要注意：

```text
~/Library
```

是当前用户的资源库。

而：

```text
/Library
```

是整个 Mac 共用的资源库。

两者不是同一个目录。

---

## 8. 显示隐藏文件

快捷键：

```text
⌘ + ⇧ + .
```

最后一个按键是英文句号 `.`。

按一次显示隐藏文件，再按一次重新隐藏。

隐藏文件通常会以半透明状态显示。

不知道用途的隐藏文件不要随便删除、移动或者修改。

---

## 9. 返回上一级文件夹

快捷键：

```text
⌘ + ↑
```

作用是直接进入当前文件夹的父目录。

例如：

```text
下载 / 项目 / 图片 / 原图
```

按一次：

```text
⌘ + ↑
```

回到：

```text
下载 / 项目 / 图片
```

另外：

```text
⌘ + ↓
```

可以打开当前选中的文件或文件夹。

### 和“返回”有什么区别？

```text
⌘ + [
```

是返回刚才访问的位置，类似浏览器的返回。

```text
⌘ + ↑
```

则是不管之前访问过哪里，直接进入当前文件夹的上一级。

---

## 10. 查看当前文件夹完整路径

除了路径栏，还有一个很方便的方法。

在 Finder 中：

```text
按住 Command + 点击窗口顶部的文件夹名称
```

会直接显示当前文件夹的完整层级，例如：

```text
Macintosh HD
→ 用户
→ 用户名
→ 文稿
→ 项目
```

点击其中任意一级，还可以直接跳转过去。

---

## 11. 在当前文件夹新建文件夹

快捷键：

```text
⇧ + ⌘ + N
```

会直接在当前 Finder 目录创建一个新文件夹。

---

## 12. 把多个文件直接放进新文件夹

如果已经有很多散乱文件，可以先把需要整理的文件全部选中。

然后：

```text
右键 → 用所选项目新建文件夹
```

Finder 会自动：

1. 创建一个新文件夹
2. 把选中的文件全部移动进去

然后给文件夹改名即可。

---

## 13. 批量重命名文件

选中多个文件，然后：

```text
右键 → 重新命名 X 个项目
```

Finder 支持：

- 替换文本
- 添加文本
- 统一格式
- 自动编号

例如：

```text
IMG_001.jpg
IMG_002.jpg
IMG_003.jpg
```

可以一次改成：

```text
旅行照片 1.jpg
旅行照片 2.jpg
旅行照片 3.jpg
```

整理照片、视频和素材时很好用。

---

## 14. 移动文件

Finder 里的文件移动逻辑和 Windows 稍微不同。

先复制：

```text
⌘ + C
```

进入目标文件夹后按：

```text
⌥ + ⌘ + V
```

文件就会从原来的位置**移动**到当前文件夹，而不是再复制一份。

可以简单记成：

```text
⌘ + C       复制
⌘ + V       粘贴
⌥ + ⌘ + V   移动到这里
```

---

## 15. Finder 四种视图

Finder 有四种主要视图：

```text
⌘ + 1    图标视图
⌘ + 2    列表视图
⌘ + 3    分栏视图
⌘ + 4    画廊视图
```

### 图标视图

适合图片、视频或者文件比较少的目录。

### 列表视图

适合大量文件，可以方便查看大小、类型、修改时间等信息。

### 分栏视图

比较适合多层目录。

例如：

```text
VLOG / 日本旅行 / Day01 / 相机 / 视频
```

使用分栏视图时，每一级目录都会单独显示一栏，切换起来比较方便。

### 画廊视图

更强调文件预览，适合图片和视频素材。

---

## 16. 查看文件详细信息

选中文件后按：

```text
⌘ + I
```

打开「显示简介」。

可以查看：

- 文件大小
- 文件类型
- 所在位置
- 创建时间
- 修改时间
- 打开方式
- 标签
- 权限

想知道一个文件有多大或者具体存在哪里时很好用。

---

## 17. 把常用文件夹放到边栏

常用文件夹可以直接拖到 Finder 左侧边栏。

例如：

```text
素材
项目
待剪辑
成片
封面
```

以后无论当前在哪个目录，都可以直接从左侧进入。

边栏只是快捷入口。

**从边栏移除不会删除真正的文件夹。**
