## 简介

无构建、无后端的单页工具：在浏览器里涂抹蒙版后做修复与增强。

- 纯 HTML / CSS / JS，可直接打开 `index.html`
- Telea 快速行进法多遍 inpainting
- 增强与锐化流水线，结果可对比后下载 PNG
- 处理均在本机完成，不依赖服务器
